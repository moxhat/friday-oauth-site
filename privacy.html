Privacy Policy

Effective date: 6 October 2026. FRIDAY is a private assistant for its owner, operated through Telegram.

Google data accessed

With the owner's OAuth consent, FRIDAY requests the drive scope. This permission allows viewing, downloading, creating, changing and deleting all files in the owner's Google Drive. FRIDAY uses it to search folders and file metadata, read selected source files, create and edit documents and spreadsheets, copy, rename, move, trash and restore files on the owner's request. Its current tools do not expose permanent deletion or sharing. It does not mirror the entire Drive to the server. Other enabled Google APIs, including Gmail and Calendar, are not connected under this authorization.

Use and sharing

Google file data is used to carry out the owner's requests. FRIDAY sends selected file excerpts and the owner's task to its configured AI model provider (currently DeepSeek Direct or an OpenRouter fallback) when analysis is needed. It does not send the whole Drive by default. FRIDAY does not sell Google user data or use it for advertising or generalized AI model training. Third-party providers process requests under their own terms and policies.

Storage and security

Drive files remain in the owner's Google account; FRIDAY does not keep a synchronized copy. When the owner asks FRIDAY to remember a Drive folder for a Telegram topic, it stores a bounded local index of that folder's file metadata and selected text excerpts on the owner's private server. The index is used only for that topic and is refreshed from Drive; it is not a complete Drive backup. FRIDAY stores its OAuth refresh token in a restricted file. Selected file excerpts and tool results may also be stored in the assistant's local SQLite conversation history and later pruned. Replies are sent to the Telegram chat or topic where the owner made the request. The app does not publish the token or Google file contents on this website.

Control and contact

The owner can revoke FRIDAY's Google access in their Google Account settings. Revocation stops future Google API access until consent is given again. To request removal of locally stored FRIDAY data or ask about this policy, contact moxhatishe@gmail.com.
